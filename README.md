# Hapin official website

English (`/`) and Simplified Chinese (`/zh-CN/`) documentation for Hapin. Other language content is no longer supported; legacy language home URLs are compatibility redirects only.

```sh
yarn install --frozen-lockfile
yarn run check
yarn start
```

Use Yarn 1.22.22 and Node 24 (LTS). dumi is pinned to 2.4.52. `yarn run check` validates paired core documentation, the versioned example snapshot, internal routes, authored TypeScript and the production build. Pull requests do not deploy; successful main pushes publish dist. CI transfers the complete site as a tarball because dumi demo routes may contain `:id`, which GitHub artifact uploads reject as a filename. The deploy job extracts the tarball before publishing.

The library documentation targets hapin-utils **5.0.0** with `context-v1` rules. `data/api-examples.json` is a fixed snapshot generated by the matching build. Its stable release channel describes the version; npm publication and website deployment remain separate maintainer actions. To update it, run the library documentation generator, copy its JSON snapshot here, run `yarn docs:sync`, then review the paired pages and run checks. No desktop dictionary or sibling checkout is required to build the site.

The playground is letter practice, not a full-text converter. Historical scheme designs are distinguished from implemented library aliases.
