## 数据范围与计数

只分析阿拉伯字母（58,632 条）与西里尔字母（8,953 条）来源词库。标签来自原字母，不来自旧 Hapin 分析器。下表统计词条内出现次数，不是实际使用频次；ngh 内部重叠的 ng/gh 不重复计入独立模式。

| 模式              | 阿拉伯来源 | 西里尔来源 |
| ----------------- | ---------- | ---------- |
| ngh：N,GH / NG,H  | 435 / 9    | 23 / 0     |
| ngye：NG / N,G    | 307 / 214  | 23 / 16    |
| 词尾 ng：NG / N,G | 5988 / 0   | 460 / 2    |
| ngul：N,G / NG    | 27 / 0     | 无样本     |

9 个 NG,H 反例包含 shanghai 及其已见词形、tunghwa 和 wanghung；词尾 ng 的反例包含源词 анг、самсунг，不能因为相似就自动合并。本次调查的 ng/ngh/gh/sh/hh 中有 13 组“同 Hapin、同位置、不同切分”冲突，与此前所有原因合计的 32 组简洁键碰撞不是同一指标。

## 验证限制

早期右侧两字符原型在 2,680 个事件的探索分组留出集上，将不符来源标签的结果由 65 次降到 59 次，只找回 65 个少数类 N,G 中的 6 个。这是早期原型，**不是当前规则实现的准确率**。前缀分组不能保证词族完全隔离，而且该留出集已被观察。

多数分布可以指导规则研发，不能证明所有新词正确。27 次 ngul 支持候选偏好，不足以形成无例外硬规则。后续规则晋级应有独立词族评估、反例及各类别误改/召回指标。

来源包含拼写变体，不是完整人工语言金标准。实际规则目录和可复现来源校验值随工具包保存；官网不分发原始整库。
