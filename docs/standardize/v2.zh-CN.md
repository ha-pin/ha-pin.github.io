## 方案版本与实现版本

哈拼方案版本、npm 包版本、切分规则版本分别管理。本文档对应正式版 **hapin-utils 5.0.0**，切分规则版本为 `context-v1`。

## 字母边界

旧 4.x 实现使用 U+200B 零宽空格作为机器字母边界。这是一种序列化约定，不是数字水印，也不是语言字母。清理中间 Hapin 字符串会让 N,GH 与 NG,H 等区别丢失。

新版在解析器和渲染器之间传递结构化字母单元，普通输出不生成隐藏边界。普通输入原有的零宽字符保留；显式使用 `inputFormat: 'legacy-boundaries'` 导入旧机器分隔数据。旧函数继续保留 `clean=false` 的序列化形式。

## 上下文切分

旧双字符贪心规则以 `legacy` 保留。5.0.0 API 结合有来源证据的词形与上下文规律，对字母切分候选排序。详见[字母切分规则](/zh-CN/standardize/segmentation)与[统计依据及限制](/zh-CN/standardize/segmentation-evidence)。

早期文档中的单引号提案（`g'h`）**尚未实现为输入分隔语法**，不能按已支持功能使用。旧 `easy` 输出中的单引号只是展示形式。需要明确区分时，传递结构化字母单元或导入旧边界数据。

## 兼容说明

已有转换函数保留签名和历史 Hapin 切分；来源边界、引号、前元音和词级作用域错误会被修复。参见[迁移说明](/zh-CN/developer/hapin-utils-migration)。方案字母表不代表每个历史别名都已实现，也不意味着所有方向完全可逆。
